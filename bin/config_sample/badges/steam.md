# steam.json

## refuse_limited (optional)

Default: `true`

No limited accounts (never bought anything).

## refuse_vac_banned (optional)

Default: `false`

No VAC bans.

## refuse_trade_banned (optional)

Default: `false`

No trade bans.

## minimum_age (optional)

Default: `0`

Account must be this many days old. 0 = off.

Profile must be public or none of this can be checked.
