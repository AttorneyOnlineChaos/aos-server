# Build Instructions
If you are unable to use either CI or release builds, you can compile kenji yourself.<br>
Requires Qt >= 6.0, and Qt websockets. Older versions may work, but are not recommended.

For instructions on how to build Kenji yourself check the [Build Instructions](https://github.com/AttorneyOnline/akashi/wiki/Building-Akashi)
